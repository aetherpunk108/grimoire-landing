1.Apa itu Merlin Agent?

Merlin adalah AI agent yang jalan di terminal — bisa membaca/menulis file, menjalankan perintah, mencari di web, mengingat konteks antar sesi, dan belajar lewat sistem skill. Satu agent, banyak platform: terminal (CLI/TUI), Telegram, Discord, dan lainnya.

Yang membedakannya dari chatbot biasa: Merlin bekerja (memakai tools), bukan cuma menjawab.

2.Install

Windows (PowerShell)

irm https://epinoiahorizon.com/install.ps1 | iex

Installer memasang Python + dependensi, launcher merlin, dan home di %LOCALAPPDATA%\merlin. Setelah selesai, tutup dan buka ulang terminal, lalu cek:

merlin --version
Troubleshooting cepat: merlin tidak dikenali → tutup semua jendela terminal, buka lagi; masih belum → jalankan installer sekali lagi (dia memperbaiki PATH non-admin). Anti-virus memblokir → beri izin; installer berasal dari repo publik epinoiahorizon/Merlin-Agent.

Linux / WSL

curl -fsSL https://epinoiahorizon.com/install.sh | bash
source ~/.bashrc        # atau buka terminal baru
merlin --version
Sudah di Windows tapi mau pengalaman Linux? wsl --install dari PowerShell, restart, lalu jalankan installer Linux di dalam WSL. Merlin native-Windows dan Merlin di WSL hidup berdampingan (home terpisah).

Prasyarat: Python 3.10+ (dipasang otomatis bila tidak ada) + internet. Dependensi lain diurus installer.

3.Setup pertama (2 menit)

merlin setup

Wizard menanyakan provider & model (Z.AI, OpenRouter, Anthropic, Ollama lokal, dll) lalu API key — disimpan di ~/.merlin/.env (Windows: %LOCALAPPDATA%\merlin\.env), tidak pernah dikirim ke mana pun selain provider-mu.

merlin doctor     # cek kesehatan instalasi
merlin model      # ganti model kapan pun

4.Pemakaian harian

merlin            # mode chat interaktif (keluar: /exit atau Ctrl+C)
merlin chat -q "jelaskan port 443 dalam satu paragraf"   # tanya cepat, tanpa sesi
merlin --continue # lanjutkan sesi terakhir
merlin --resume <session-id>   # lanjut sesi spesifik

Perintah penting di dalam sesi:

PerintahFungsi
/helpdaftar semua perintah
/modelganti model di tengah sesi
/compactpadatkan context saat sesi berat (hemat token)
/sessionslihat sesi-sesi lama
/skillsdaftar skill yang bisa dimuat
/skinganti tema tampilan
/exitkeluar

5.Kemampuan inti

Coding — "review app.py, cari bug, perbaiki, jalankan test": Merlin membaca, mengedit, mengeksekusi test, lalu melaporkan hasilnya.

Riset web — "cari dokumentasi resmi X, rangkum 5 poin + link" (toolset web aktif).

Otomasi — pasang cron job dari dalam sesi, misal pengecekan integritas data tiap pagi.

Ingatan permanen — "ingat: repo utama saya di Y" — tersimpan dan dipakai di sesi berikutnya.

Skills — kemampuan tambahan on-demand; contoh skill caveman membuat jawaban super hemat token.

7.Config & lokasi file

ApaLinux / WSLWindows
Config~/.merlin/config.yaml%LOCALAPPDATA%\merlin\config.yaml
API keys~/.merlin/.env%LOCALAPPDATA%\merlin\.env
Skills~/.merlin/skills/%LOCALAPPDATA%\merlin\skills\
Memory~/.merlin/memories/%LOCALAPPDATA%\merlin\memories\
Riwayat sesi~/.merlin/state.db%LOCALAPPDATA%\merlin\state.db
Jangan edit config.yaml manual kalau ragu — satu indent salah bisa merusak. Pakai: merlin config set <key> <value>. Update Merlin: merlin update.

8.Bonus: Merlin di Telegram

# 1) buat bot via @BotFather di Telegram, simpan token-nya
merlin config set channels.telegram.token <TOKEN>
merlin config set channels.telegram.enabled true
merlin gateway run

Butuh mesin yang menyala terus (VPS atau PC sendiri). Panduan lengkap: docs resmi.
