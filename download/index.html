Installer · 104 MB · v0.1.2

Installs per-machine into C:\Program Files\Merlin, adds shortcuts and an uninstaller. First launch sets up the agent runtime (internet required) or connects to a Merlin install already on the machine. Asks for administrator approval once. 0.1.2 opens with a solid window on PCs without the Windows 11 glass material, and bootstraps even when its build commit is not on GitHub.

What is inside

  • Electron desktop app
  • Agent runtime — CPython 3.14.7 + venv with 49 extras
  • git, ffmpeg, chromium (browser tool)
  • Skills, memory, cron, gateway

What was trimmed

  • llama.cpp CUDA/HIP builds (~1.8 GB) — local GPU inference only
  • uv cache (~1 GB) — only for offline plugin installs
  • Daytona backend — no CPython 3.14 wheel for its dependency

Requirements

  • Windows 10 or 11, x64
  • Installer: ~400 MB in Program Files, admin approval once
  • Portable: ~4 GB free disk, no admin rights
  • An API key for any model provider
