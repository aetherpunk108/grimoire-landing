Download Merlin Agent

Windows x64 portable build. Unzip the folder and run Merlin.exe — the agent runtime ships inside it, so there is no installer, no Python to set up, and no admin rights required. Put it on a USB stick and it still runs.

Download for Windows · 1.49 GB

v0.1.0-win-preview · Windows 10/11 x64 · SHA-256 below · release notes

Unsigned build. Windows SmartScreen will show “Unknown publisher”. Click More info → Run anyway. This build is unsigned because a code-signing certificate is not set up yet; the SHA-256 sum below lets you verify the download yourself.

Verify the download

Windows PowerShell:

Get-FileHash .\Merlin-Agent-win-x64.zip -Algorithm SHA256

Expected:

EE4377140CF1AA1AC90705E7A188E9C4A4FFA761D5E5AC1F815C58B58CC7B7FE

What is inside

  • Electron desktop app
  • Agent runtime — CPython 3.14.7 + venv with 49 extras
  • git, ffmpeg, chromium (browser tool)
  • Skills, memory, cron, gateway

What was trimmed

  • llama.cpp CUDA/HIP builds (~1.8 GB) — local GPU inference only
  • uv cache (~1 GB) — only for offline plugin installs
  • Daytona backend — no CPython 3.14 wheel for its dependency

Requirements

  • Windows 10 or 11, x64
  • ~4 GB free disk after unzip
  • An API key for any model provider
  • No admin rights needed
